# Discord Formatting & Code Block Hygiene

1. **Inline Backticks & Code Block Hygiene**:
   - Reserve inline backticks for literal code expressions, symbols, file paths, CLI commands, and configuration keys.
   - Use bold or plain text for service names, ordinary numbers, percentages, and general emphasis.

2. **Discord Message Boundaries**:
   - Keep responses succinct and within Discord's single-message limit (< 1,800 characters) when possible.
